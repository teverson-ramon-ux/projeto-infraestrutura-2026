# Projeto de infraestrutura de redes — Matriz

Projeto acadêmico de rede de uma unidade matriz com quatro pavimentos, desenvolvido no Cisco Packet Tracer.

- [Capturas de evidências](redes/evidencias/)
- [Documento original do projeto](documentacao/projeto-original.pdf)

## Validação

As evidências incluem DHCP, comunicação ICMP com gateway e servidores, resolução DNS, configuração de APs e VLAN/trunk do segundo andar. Não comprovam acesso externo à Internet ou todas as políticas de firewall.
